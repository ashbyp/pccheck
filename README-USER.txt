PC Performance Diagnostic Tool
==============================

What this does
- Collects diagnostic information from your PC while it is slow.
- Saves results to your Desktop in a folder named:
  PCDiag_YYYYMMDD_HHMMSS
- Also creates a .zip file you can send back to support.

How to run (easy)
1. Right-click the downloaded zip and choose "Extract All".
2. Open the extracted folder.
3. Double-click: Run-PCDiagnostics-Fast.bat

If support asks for a deeper capture
- Run-PCDiagnostics.bat (Quick mode)
- Run-PCDiagnostics-Full.bat (Full mode, longest)

What to send back
- On your Desktop, find the newest file named:
  PCDiag_....zip
- Send that zip file to support.

Troubleshooting
- If Windows blocks the script:
  Right-click the .bat file and choose "Run as administrator".
- If SmartScreen appears:
  Click "More info" then "Run anyway" (only if provided by trusted support).
- Keep the command window open until it says the run is complete.

Privacy note
- The tool collects system diagnostics (processes, events, services, device info).
- It does not intentionally change system settings.
